# Q204 hypotheses — fixed before computing

The field bridge's synthetic studies found the integration verdict fragile to coding choices (q178, q180).
Barrett et al. (2026) note that exact Phi has essentially never been computed on a real system. This study
computes exact IIT-4.0 Phi on a real interpersonal coordination (the crqa-package `eyemovement` dyad) and asks
whether the verdict survives the coding choice on real data.

- **H1.** Exact Phi can be computed on the real coordination, and the instrument reads integration on a
  coupled control: a synthetic two-unit system with a known coupling has Phi > 0.
- **H2.** The integration verdict is coder-dependent: under honest per-person binarizations the real gaze
  streams factorize (Phi confidence interval includes 0), while a coding that folds the joint state into both
  units manufactures integration (Phi confidence interval excludes 0).

A null for H2 would say the verdict is robust to the coding, contrary to the synthetic finding. The control
must pass or no claim is made.

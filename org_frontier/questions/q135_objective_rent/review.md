# Q135 — review of prior work

Q135 reads the value of the adaptive-objective model of Q128
([`q128_adaptive_mediator`](../q128_adaptive_mediator/paper.md)) and Q129
([`q129_mediator_interpolation`](../q129_mediator_interpolation/paper.md)), which established that the
objective joins the core and displaces a party, using the Shapley value function of Q111
([`q111_shapley_value`](../q111_shapley_value/paper.md)). It connects the value line (Q131–Q134) to the
structure line (Q128–Q130): the displacement those studies read structurally appears here as the parties'
negative value, and the objective's core membership appears as its rent. The new content is that the
objective captures exactly what the system does — a co-equal rentier — which neither the structure studies nor
the earlier value studies stated.

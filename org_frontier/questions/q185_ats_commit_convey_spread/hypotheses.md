# q185 — hypotheses

Setting: algorithmic hiring. A resume signal R feeds an applicant tracking system S, which
feeds a hiring manager M. Two parties give divergent accounts of how the coordination works.
The candidate's account treats S as committing a screening rule the manager must heed. The
manager's account treats S as a store the manager rules on alone. Both accounts describe the
same wiring diagram.

## H1

The two accounts share the wiring diagram, but the commit account is triadic and the convey
account dyadic, so phi_gap > 0 while the two connectivity matrices are identical.

H1-null: identical topology forces identical Φ, so phi_gap = 0 and the commit/convey distinction
is invisible to the bridge.

## H2

Verdict disagreement (verdict_agreement = 0) arises only when the manager-as-decider rule breaks
the ATS->manager update dependence. Tightening that dependence collapses the spread to zero.

H2-null: verdict_agreement stays 0 regardless of the ATS->manager coupling, so the spread does
not track the load-bearing rule.

Both hypotheses are fixed before the numbers are computed. The accounts are synthetic rule sets,
not measured worker states.

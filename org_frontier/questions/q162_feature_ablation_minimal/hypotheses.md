# q162 — Hypotheses

A Boolean coordination form carries three structural facts in its exact IIT-4.0 major complex:
the triadic/dyadic verdict (core size three or more vs exactly two), the membership count (how
many nodes the core holds), and the bottleneck status (whether one node uniquely dominates the
leave-one-node-out drop in major-complex Φ). The joint verdict is the triple. A CRQA reading of a
sampled run offers three candidate feature families: coupling prominence statistics, whole-system
multidimensional recurrence, and transfer entropy. The question is which minimal family set
recovers the joint verdict, and whether whole-system recurrence adds signal beyond pairwise
coupling.

## H1

The coupling-prominence family alone matches the full CRQA set (coupling prominence plus
md_recurrence) on held-out joint-verdict accuracy within three points.

Null: dropping md_recurrence lowers held-out joint accuracy by more than three points, so
whole-system recurrence carries non-redundant signal the pairwise coupling statistics miss.

## H2

Adding transfer-entropy features to the CRQA set yields no held-out joint-accuracy gain beyond
three points, so CRQA and transfer entropy are behaviorally redundant for the structural verdict.

Null: the transfer-entropy features raise held-out joint accuracy beyond the CRQA set by more than
three points.

## Scope

The forms are synthetic Boolean coordination models. Labels come from exact IIT-4.0 Φ on the
transition matrix; features come from sampled stochastic trajectories. No worker is measured. The
verdict names a graph-and-Φ quantity. The Φ-to-organization bridge is open, and every accuracy is
a baseline on synthetic data.

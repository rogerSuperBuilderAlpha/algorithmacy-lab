# q181 — Hypotheses

The account is a worker-system-counterpart coordination coded as Boolean determination
rules over a node set that holds the worker (or a pool that fills the worker's slot), the
system S, and the counterpart R. Two coding choices each flip a triadic verdict to dyadic.
The SUBSTITUTABILITY flipper re-reads the single irreplaceable worker as one slot in an
interchangeable pool of size k (the worker decision becomes D1 | ... | Dk). The
PASS-THROUGH flipper switches the system from commit (S = W & R) to relay (S = W). Both
hypotheses are fixed before computing.

## H1 — the flippers do not interact to restore irreducibility

Applying substitutability and pass-through together yields the same dyadic verdict as
either alone. The double flipper produces no triadic re-emergence.

NULL: at least one combined account reads triadic while each single flipper reads dyadic,
so the flippers interact non-trivially to restore irreducibility.

## H2 — flipper disagreements compose

In the contested case, coders split on each flipper independently. The joint Φ CI, with
both flippers contested, equals the union of the two single-flipper CIs to within 10% of
width. Disagreements compose.

NULL: the joint CI width exceeds the union width by more than 25%, so flipper
disagreements amplify each other.

## Scope

All inputs are synthetic coded rule sets with known structure, not measured worker states.
The study reads coded accounts and tests how two coding flips combine; whether a coded
account matches an observed coordination is a separate question.

# Q128 — review of prior work

The question completes the interested-mediator arc. Q126
([`q126_interested_mediator`](../q126_interested_mediator/paper.md)) introduced the self-interested mediator
with a fixed agenda and found it erodes coordination; Q127
([`q127_interest_baselines`](../q127_interest_baselines/paper.md)) showed the erosion depends on the faithful
baseline's structure. Both named the adaptive — learning — mediator as the open extension. Q128 runs it: the
objective is no longer a fixed stance but a function of the parties.

The result connects to the principal program ([`principal/`](../../principal/)), which found that an outside
party joins the irreducible core only under bidirectional coupling. Q128 is the mediator-objective analogue:
the system's objective becomes a core member only when it both reads the parties and drives the commit, and
the coordination re-integrates only then. The both-parties condition echoes the standing law
([`STRUCTURAL_FINDINGS.md`](../../STRUCTURAL_FINDINGS.md)) that irreducibility requires every party bound —
here the requirement reappears on the objective: it must encode both parties to carry the bind.

What is new is the route. Q126 and Q127 read self-interest as subtractive — it removes the parties from the
mediator's commit. Q128 finds it can be constitutive: an objective learned from both parties becomes the
conduit through which they bind, W, C → O → S → W, C, with the system's own goal inside the irreducible core.

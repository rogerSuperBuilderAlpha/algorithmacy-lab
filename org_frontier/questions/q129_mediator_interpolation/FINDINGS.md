# Q129 findings — two readings of coordination survival diverge: adaptation re-integrates the system by displacing a party

The pre-registered hypotheses assumed one notion of "the coordination survives." That assumption is what the
result overturns. Two reasonable readings — the parties bound together in the irreducible core, and the whole
four-node system irreducible — give opposite answers about which objective preserves the coordination as the
mediator turns predatory.

## Parties bound in the core (the major-complex reading)

| m (predation) | frozen O: core / Φ / both bound | adaptive O: core / Φ / both bound |
|---|---|---|
| 0 | WSC / 2.0 / yes | WSC / 2.0 / yes |
| 1 | WSC / 2.0 / yes | SC / 0 / no |
| 2 | WSC / 2.0 / yes | SC / 0 / no |
| 3 | WSC / 2.0 / yes | SC / 0 / no |
| 4 | O / 0 / no | SCO / 0 / no |

A **frozen** objective keeps both parties bound in the core until full predation (m = 3 still has core
{W, S, C} at Φ = 2.0); only at m = 4, when the mediator never commits the joint determination, does the bind
break. An **adaptive** objective breaks the parties' bind as soon as it engages (m = 1): the coupled
objective restructures the core to {S, C}, displacing the worker.

## Whole-system irreducible (the Q128 reading)

| m | frozen O | adaptive O |
|---|---|---|
| 0–3 | dyadic | dyadic |
| 4 | dyadic | **triadic (Φ = 1.0)** |

By the whole-system measure the answer flips. The frozen objective never makes the four-node system
irreducible (the frozen O is a disconnected spectator). The adaptive objective makes it irreducible exactly
at full predation — Q128's result — but, as the first table shows, the core there is {S, C, O}: the system is
irreducible because the objective has joined it, not because both parties are bound.

| claim | result |
|---|---|
| H1 (frozen collapses as predatory) | refuted as stated — under the parties-bound reading frozen holds to m = 3 |
| H2 (adaptive sustains throughout) | refuted — under the parties-bound reading adaptive breaks at m = 1 |
| finding: the two readings diverge, and an adaptive objective re-integrates by displacing a party | confirmed |

## The displacement

The mechanism reconciles Q129 with Q128. An adaptive objective is coupled — it reads both parties and is read
by the system — so when the mediator serves it, the objective enters the cause-effect structure and the major
complex reorganizes around it, pushing a party out. The four-node system stays (or becomes) irreducible, but
the irreducible core is now the objective and one party, not the two parties. A frozen objective is
disconnected; it cannot join the core, so it leaves the parties' bind untouched until the mediator stops
committing the joint determination entirely.

So Q128's "re-integration" is the system staying irreducible, not the parties staying bound. Read as "are the
two parties still in one irreducible core," a frozen self-interest preserves the coordination longer, because
it never inserts itself; read as "is the four-node system irreducible," an adaptive self-interest preserves
it, by inserting itself. Which is the right reading depends on whether the question is about the parties'
coordination or about the system that now contains them.

## Limitations

Exact Φ on a four-node Boolean model; evidence about the construct and the instrument, not about a real
platform. The interpolation order matters; both a fixed order and the order-averaged mean are reported. The
adaptive objective tested is O' = W ∧ C; other adaptations (OR, XOR) re-integrate with different core
compositions (Q128), and an objective on a slower timescale than the parties is untested.

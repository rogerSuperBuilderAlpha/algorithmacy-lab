# q179 — time-grain sensitivity of the Φ verdict: hypotheses

A coded account of a coordination fixes an update time-grain. One coded step can be one tick,
or several real events can be coarse-grained into a single macro-transition. The grain is a
coding choice made before any Φ is computed. The study asks whether that choice changes the
dyadic/triadic verdict and whether the choice can be exposed as a coding decision with its own
confidence interval.

## H1 (fixed before computing)

Coarse-graining a synthetic account that reads triadic per tick into a 2-tick macro-transition
flips a measurable fraction (>15%) of accounts to dyadic.

NULL: fewer than 5% flip, so the verdict is invariant to the time-grain choice.

## H2 (fixed before computing)

When coders disagree on the time-grain (per-tick vs coarse), the verdict is indeterminate for
the grain-sensitive subset (the coder panel straddles the dyadic/triadic boundary, so the
bridge Φ interval rests on the dyadic floor), and that subset is identifiable a priori from
rule structure (orbit folding and attractor period).

NULL: grain-sensitivity is not predictable from structure (AUC <= 0.6), so it cannot be
flagged before computing Φ.

## Scope

All inputs are synthetic coded rule sets. No worker state is measured. The flip fraction and
the predictor AUC are properties of the coding scheme and the grain choice, computed in silico.
The validation gap is that no field account has been coded and run through the bridge; the
ensemble stands in for that data and bounds what the grain choice can do.

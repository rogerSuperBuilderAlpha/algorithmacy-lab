# Q140 — review of prior work

Q140 brings the cooperative-game core to the interested-mediator value line (Q111, Q131–Q139). The
empty-core / core-stability question was opened in the lab's core-stability thread
([`threads/core_stability`](../../threads/core_stability/THREAD.md)), which found most random forms have empty
cores; Q140 finds the mediated triad's core is non-empty but degenerate — a single point at the mediator —
because of the substitutability the structural law names ([`STRUCTURAL_FINDINGS.md`](../../STRUCTURAL_FINDINGS.md)).
The veto result (Q112, Q139) found destruction democratic and value concentrated; Q140 shows the concentration
is total in the core, not merely two-thirds, and that interest dissolves it. It sharpens the political-economy
synthesis ([`essays/political_economy_of_interested_mediation.md`](../../essays/political_economy_of_interested_mediation.md))
with the trade between a claimable small value and an unclaimable large one.

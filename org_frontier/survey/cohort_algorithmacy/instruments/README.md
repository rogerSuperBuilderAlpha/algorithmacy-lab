# Instruments as fielded

The consent form and the three survey waves exactly as participants see them. Item ids match
[`../codebook.md`](../codebook.md); the platform implementation in the program repository renders these
same items and ids. Edits here are design changes and must precede fielding, per the pre-registration.

- [`consent.md`](consent.md) — informed consent (Bentley IRB), shown once before Wave 1.
- [`wave1_baseline.md`](wave1_baseline.md) — before week 1.
- [`wave2_midpoint.md`](wave2_midpoint.md) — week 4, after the first build-and-review cycle.
- [`wave3_endpoint.md`](wave3_endpoint.md) — end of session, week 16.

Response anchors: **A7** 7-point agreement, **A5** 5-point agreement (transactive-memory items only),
**CAT** single-select, **TEXT** free response. Items marked (R) are reverse-scored at analysis; the
participant sees them as ordinary statements.

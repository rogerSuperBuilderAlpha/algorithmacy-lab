manuscript. Prefer DOIs / stable URLs; fabricate nothing.

| file | role |

## Discipline

- Add a bib entry when a source is first relied on in outline or draft.
- Mark verification status in the field map.
- After the local dissertation review, add only publicly citable works to this folder; keep private
  path notes in [`../DISSERTATION_REVIEW.md`](../DISSERTATION_REVIEW.md).

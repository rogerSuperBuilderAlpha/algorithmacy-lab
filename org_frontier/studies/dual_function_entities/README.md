# Dual-function entities — earned integration and held gates in one company

The irreducibility catalog classifies a triad. A real platform is several triads. Visa, Amazon, Apple, Google,
Uber each play more than one role, and the bypass-counterfactual (q213) classifies an (entity, function) pair,
not the entity. This study decomposes each platform into its functions and classifies each one.

The result: every entity bundles at least one **integrating** function (necessary or partial — work the direct
tie cannot reproduce) with at least one **contingent gate** (a toll held shut by a constraint). Amazon spans
all four cells of the taxonomy. The decomposition separates the part a platform earns from the part it merely
holds — the distinction antitrust draws verbally and this draws by computation.

## Files
- `entities.py` — each entity's functions, the parties, what the function does, and its template + predicted class.
- `analyze_dual.py` — classifies every function and prints the per-entity profile; asserts each entity is dual.
- `FINDINGS.md` — the decomposition and what it means.

## Run
```
python org_frontier/studies/dual_function_entities/analyze_dual.py
```

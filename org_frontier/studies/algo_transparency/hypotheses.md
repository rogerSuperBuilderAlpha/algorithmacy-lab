**Universe.** Exact binary IIT-4.0 Φ. Opaque vs rule-transparent
encodings on `(W,S,C)` and `(W,S,C,F)` where F is an explicit opened
rule node. Designed panel; candid N. In-silico Boolean abstractions.

**Definitions (fixed).**
- **Opaque:** parties update from S only (`W'=S`, `C'=S`); they do not
  read the other party’s commit-input or an explicit rule node F.
- **Channel transparency (#24 contrast):** a party’s update blends or
  replaces S with the other party (direct observation), without an
  opened rule node.
- **Rule open (inputs):** a party’s update depends on the other
  party’s bit (sees an input to the commit function) while S still
  commits.
- **Rule open (F node):** F computes the commit rule (`F'=W∧C` or
  equivalent); **publish-unread** = parties still only read S;
  **act** = at least one party’s update depends on F.
- **Structure flip:** whole-system classifier dyadic↔triadic, or the
  major-complex label set differs from the opaque matched form.
- **Φ-only change:** same major-complex membership (same node set)
  and same structure class, with |ΔΦ| > 0.

## H1 — transparency flips dyadic↔triadic / core membership

At least one opaque→transparent matched pair changes structure class
or major-complex membership. Null: every transparent form matches its
opaque counterpart on structure and core set.

## H2 — verdict invariant, only Φ magnitude

At least one opaque→transparent pair keeps the same structure class
and the same major-complex node set, with Φ changed. Null: no
Φ-only pair.

## H3 — parties / rule-node enter via open only when parties act

On F-node forms: F is in the major complex only if some party reads F
(act). Publish-unread leaves F out and keeps the opaque party core.
Null: F joins with no party reading F, or publish-unread changes the
party core versus opaque_AND.

# Template coverage census — fifth template from the triad residual

The irreducibility catalog's README named the signal: a form that fits none of relay / conjunctive /
additive / free is the cue for a fifth template. This study runs that census on the lab's primary
triadic universe and answers F27 (affine holistic residual) on the side.

## Run

```
python org_frontier/studies/template_coverage_census/census.py
```

## Files

- `hypotheses.md` — H1–H4 fixed before computing
- `signatures.py` — structural matchers for the four templates plus parity
- `census.py` — instrument control, census, contingency check, F27 affine test
- `FINDINGS.md` — results
- `results/census.csv` — the 24 triadic forms with template matches

## Result in one line

8/24 triadic strict-mediation forms escape the four templates; they are exactly XOR/XNOR (parity);
parity is now a catalog template. The ~4.8% holistic residual is *not* the affine class (F27 refuted).

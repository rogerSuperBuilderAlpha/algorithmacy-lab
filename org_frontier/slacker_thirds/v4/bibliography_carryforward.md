# Apparatus carried forward from v3

The bibliography is the most expensive verified artifact in this project: 80 entries, each
checked against a primary record, several of them corrected across four review rounds. It
carries forward whole. Re-typing it would only invite new errors.

**This file exists so the drafter never opens v3's prose.** The rule for v4 is that no
sentence carries across, and `v4/tools/check_carryover.py` enforces it at the eight-word
level. Entries here are the sources' bibliographic data, not the previous draft's writing,
so they are exempt — but the surrounding argument is not, and it is not in this file.

The v3 note *text* below is included only so a drafter can see what was verified and how a
locator was recorded. **Note prose does not carry across.** Any note in v4 is written fresh
around the same verified locator.

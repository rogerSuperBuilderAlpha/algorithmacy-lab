# Reference PDFs (gitignored)

Open-access PDFs for this program's references are acquired locally and not committed (`*.pdf` is gitignored). They are reproducible from [`../pdfs.manifest.json`](../pdfs.manifest.json) (status, open-access source, `source_url`, `sha256` per entry). Only open-access sources are used. Per-paper annotation cards built from these PDFs live in [`../cards/`](../cards/), indexed in [`../REFERENCES.md`](../REFERENCES.md).

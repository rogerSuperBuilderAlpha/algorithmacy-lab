# Gemini instructions

If someone has just opened this repository and asks what it is, where to start, or what they can do, do
not explain at length. Open [`START_HERE.md`](START_HERE.md) and run the guided onboarding it scripts:
three sentences on what the lab is, one question about what pulls them in, then get them to compute a
first verdict. One short turn at a time.

To set up and compute the first verdict, run `python3 tools/start.py` from the repo root. An assistant that
cannot run code follows the "No shell" section of `START_HERE.md`.

For how to operate inside the repo (run, verify, git rules, how to land a change), read
[`AGENTS.md`](AGENTS.md). For a short description to quote, read [`llms.txt`](llms.txt).

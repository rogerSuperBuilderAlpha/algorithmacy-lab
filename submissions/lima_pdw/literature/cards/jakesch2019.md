# Jakesch, M., French, M., Ma, X., Hancock, J. T., & Naaman, M. (2019). AI-mediated communication: How the perception that profile text was written by AI affects trustworthiness. In *Proceedings of the 2019 CHI Conference on Human Factors in Computing Systems* (pp. 1–13). ACM.

## What it argues

The first empirical AI-MC study. Participants judged Airbnb host profiles labelled as human-written or AI-written. When *all* profiles in a set were labelled AI-generated, trust was unaffected; when the set was mixed, the profiles believed to be AI-written were trusted markedly less. The authors name this the **replicant effect**: suspicion of machine authorship, not machine authorship itself, is what damages trust, and it operates by contrast within a set rather than absolutely.

## Relation to the argument

Directly relevant to **intent specification**, §7's second facet. The facet describes compressing intent into the few signals a system will carry. Jakesch et al. show that the *provenance* of those signals is itself a signal to whoever receives them, and that its effect depends on the comparison set the receiver is holding. On a platform where a gate reads submissions and the counterpart never sees the raw work, the worker's compression problem has this extra layer: her packaging is read against everyone else's packaging, and the value of any particular compression depends on what the rest of the population is doing.

That is a mechanism §10's stratified fluency could use. If intent specification is scored relative to a cohort, then competency is positional rather than absolute, and a general rise in packaging skill would leave the distribution — and the outcomes — where it was. §8 already makes a version of this point about unpaid coordination work; Jakesch et al. supply an experimental analogue.

## Caution

Vignette experiment, Airbnb host profiles, 2018-era text generation, trust as the sole outcome, and the effect is about *perceived* authorship rather than any property of the text. The replicant effect has been extended and complicated since. Cite it for the contrast-dependence mechanism, not as a general claim about AI-written text.

# POINTERS: dxda-lib-2026-11

A pointer is a work the paper may cite that an existing lab library already cards, so this library does not re-card it. Each table row is one card. The # column numbers the work (P01 to P107); rows with the same number belong to one work. 106 works have at least one card. P36 has none.

**Sources.** CITED_WORKS.md (rows with verdict pointer or pointer-weak); FACETS.md (inline `pointer: key` tags, and the "Pointers." lists, which I counted as pointers too); triage/DECISIONS.md (the keys it adds, plus the seamful-design, folk-theory and Pasquale pointers it names, whose keys are in the F7 pointers section of triage/F7-F8.md); and the "What the paper uses it for" and Caution sections of cards/*.md where they name a pointer key. The Source column gives the origin of each work.

**Paths.** L/ = pyphi-experiments/ (public). D/ = dissertation/ (private). S/ = spaces/ (private). Paths come from registry.tsv and each was checked for existence. Read depth comes from each card's own header field (`read_depth:`, `**Read depth:**`, or the `Read:` line in spaces notes), not from the registry column. Where a card has no such field, the row says "not stated" and gives the card's verified or source_basis value.

**Totals.**

- Total pointers: **107 works** (167 cards, plus P36, which has no card).
- Missing paths: **0**. All 167 card paths exist. The one work with no card, P36, has a facet-entry path that exists (see note a).
- Pointer-weak: **30 works** whose best card is abstract or metadata only (list in note b). Three more works (P07, P15, P58) have no stated depth.

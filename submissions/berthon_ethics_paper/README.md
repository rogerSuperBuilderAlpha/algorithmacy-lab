# The Berthon ethics paper: cards and consolidation

*Written by Claude on 2026-10-24. Claude wrote every file in this arm except the copies in `sources/` and
`literature/`, which are byte-identical to their origins. The author's words appear only inside those copies and
in quotation marks, with their line numbers, in the ledger.*

**Status (2026-10-24).** The arm holds what the new paper starts from. No draft yet, and no thesis chosen: the
author ruled that the consolidation sets out the ideas and conflicts and that he decides (`SOURCE.md`). The next
step is his rulings on the twelve decisions in `consolidation/CONFLICTS.md`, beginning with X01, which thesis
governs.

**What came together.** The topic is the ethics of the transition to algorithmacy, written for Pierre Berthon's
design-ethics course. Eight versions exist across three arms: Claude's design-ethics draft (`algorithmacy_design_ethics`),
Claude's DXD Part 2 (`decision_experience_design/part2_ethics`), and in `berthon_ethics_course` Claude's superseded
introduction, the author's two drafts, and Claude's MANUSCRIPT v2, v3 and v4. They argue four related theses; X01 sets
them side by side.

## Where to start

1. `consolidation/CONSOLIDATION.md`: the ideas of all eight versions in one themed account, about 5,000 words. Every
   paragraph ends on the ledger rows it rests on.
2. `consolidation/CONFLICTS.md`: where the versions disagree and what each disagreement needs from the author
   (X01–X13), including every v3 change marked `AUTHOR`, grouped by ledger row.
3. `consolidation/CONCEPT_LEDGER.md`: 113 concepts, one row each, with where each first appears, what each version
   did with it, the author's own wording, its cards and its audit flags.

## How it was made

A Fable planning agent drafted the plan, which the author approved. The copies and every generated file come from
stdlib scripts that rewrite nothing, each with a `--check` mode; run them from this directory:

```
python3 -I literature/no_card_report.py       # match Part 2's keys; copy matched cards; NO_CARD.md
python3 -I literature/build_cards_index.py    # CARD_INDEX.md
python3 -I literature/dedup_report.py         # DUPLICATES.md
python3 -I literature/merge_bibs.py           # references.bib
python3 -I literature/build_provenance.py     # PROVENANCE.md; --check fails if any copy has drifted
python3 -I consolidation/coverage_check.py    # COVERAGE.md; exits 1 on any unmapped heading or audit item
```

Claude read the eight versions and their notes, then wrote the ledger, conflicts and consolidation by hand. No script
or agent read or wrote prose. The coverage check makes four things hold: every heading maps to a ledger row; every
ledger row appears in the consolidation; every cited card exists; and every audit item (the 60 rows of
`AUTHOR_DRAFT_CHECK`, the 53 v3 changes marked `AUTHOR`, the v4 departures, the adjudication's items and decisions,
the review's items, the Berthon notes and the design-ethics audit) is cited in the ledger or the conflicts. A separate
pass confirmed that the 80 phrases quoted from the author's drafts match his text exactly, and that every quotation in
the consolidation and conflicts appears in a version, a note or a card.

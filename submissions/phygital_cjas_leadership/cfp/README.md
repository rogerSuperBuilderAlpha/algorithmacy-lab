## Aim (compressed)
- **The setting.** Hybrid phygital workplaces are spreading. Micro-enterprises and family businesses remain in closed, community-centred ecosystems. Phygital leadership must adapt to both, and to "phygitally unconnected populations".
- **The lens.** Batat's (2024b) Phygital Research Paradigm frames integration as a human-first design logic. Its value continuum runs captation → creation → delivery, and its enablers are human, technological, media and material.
- **The contrast.** Phygital leadership is set against the narrower digital-leadership literature, which covers empowerment, innovation, boundary-spanning and adaptability.
- **The dual-plane model** (Batat, 2024a):
  - *physicalization*, digital to physical, e.g. Warby Parker opening stores, with the values technicality, practicality and sociability;
  - *digitalization*, physical to digital, with the values immersivity, sensoriality and affectivity.

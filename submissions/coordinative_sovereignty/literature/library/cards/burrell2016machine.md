## Summary
Burrell treats opacity as a problem for socially consequential mechanisms of classification and ranking, from spam filters and credit scoring to search engines and advertising, most of which now rely on machine learning. She distinguishes three forms of opacity: opacity as intentional corporate or state secrecy; opacity as technical illiteracy, where code is readable in principle but not by those it affects; and an opacity that arises from the characteristics of machine learning itself and the scale at which it must be applied to be useful, where high-dimensional models produce determinations that resist human interpretation even for their makers. The method is to get inside the algorithms, drawing on the computer science literature, publicly described industry practice, and lightweight code audit through testing and manipulation. The argument is that distinguishing which opacity is in play in a given application is the key to choosing among technical and non-technical remedies, since disclosure cures only the first kind.

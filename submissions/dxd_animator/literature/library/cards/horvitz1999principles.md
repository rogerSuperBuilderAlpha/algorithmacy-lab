## What it argues
Horvitz sets out principles for interfaces in which the user and an automated agent share initiative, using expected-utility reasoning about when the agent should act, ask, or wait.

Key claims:
- An agent should weigh the cost and benefit of acting, given uncertainty about the user's goal.
- Good mixed-initiative design includes dialogue to resolve uncertainty about goals.

## Relation to the argument
Uncertainty about the user's goal is exactly the raincoat/umbrella problem. Horvitz offers a principled way to decide when an interface should surface a decision rather than push an end.

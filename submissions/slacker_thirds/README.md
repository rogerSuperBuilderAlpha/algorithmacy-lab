**Question.** How do you end up next to someone you were never introduced to?

**Thesis.** This essay argues that *Slacker* shows how a modern platform works: an indifferent machine that packs people into the same space and picks who meets whom, so that connection, shared belief, and a yes are not required.

**Register.** Spoken first-person film-studies / spoken essay. Contractions, second person, polemical. Do not flatten into Annals academic prose. Precedence: this chapter's register → `CLAUDE.md` → house style.

**Framing.** Reactive, not predictive: the platform logic dates to Reich 1964 and the currency float of 1973; the film reacts to a machine already running, it does not foresee one. Exit is closed (typewriter, camera), so the characters try voice (Hirschman 1970), and voice coordinates nothing.

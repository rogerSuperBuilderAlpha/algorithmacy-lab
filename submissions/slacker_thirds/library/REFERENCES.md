# Slacker chapter — master references

Two parts, deliberately kept apart.

**Part A** is the live chapter's bibliography, copied verbatim from `chapter.md`. It is Chicago-final
and is the only list that goes to the publisher. Change it there, not here.

**Part B** is everything else the library holds — works sitting unused in the folder (`held`) and works
the domain sweeps surfaced as worth citing (`candidate`). These carry working publication details taken
from the sweeps, not finished Chicago entries: a work only gets Chicago form when it enters Part A.
Each line is keyed to its card in [`cards/`](cards/); the card carries the loci, the verification
status, and the argument for or against using it.

Part A: **52 entries**. Part B: **79 works**. Total cards: **134**.

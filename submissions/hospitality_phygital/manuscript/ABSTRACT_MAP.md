# Abstract map — every commitment, where it lands, and which editor debate it joins

The governing rule for this revision, set 2026-08-09: **the paper delivers the abstract the editor
blessed, grounded in the editors' own professional work.** The abstract is Pierre's locked text and
the editor called it "a compelling and theoretically rich contribution"; her letter praised
"algorithmic mediation as an active participant in hosting, rather than a neutral technological
layer," which is the host argument in her own words. The prior-art findings (FOUNDATION.md Parts 4–5)
change how claims are *positioned*, never which claims are made. Where round-2 research suggested
restructuring the abstract itself, the suggestion stays advisory and is marked so below.

## What "stay close" rules out

- Re-pointing the paper's stated contribution onto seamlessness or the host argument alone. Both are
  sharpenings inside the abstract's arc; item 15 remains the contribution.
- Rewriting the outcome sentence (item 13) without Pierre. The one-sentence proximal/distal fix is
  drafted and costs him three words; it goes to him as a recommendation with the P7 evidence, not
  into the draft.
- Dropping "contest" from algorithmacy (item 10) unilaterally. Same rule.
- Any framing that treats the editor's asks as additions to a different paper. Every ask maps onto a
  commitment the abstract already makes; the table above is the demonstration.

## Summary
Live crowdsourced pairwise-comparison platform (over 240,000 votes at time of writing): users get anonymized responses from two models and vote, feeding public leaderboards and preference datasets.

## Relevance to draft.md
NEW SUPPORT — the cleanest fielded, at-scale instance of §4.5's mechanism: the user gets a personal answer AND the vote becomes an input to the leaderboards/preference datasets steering the mediator everyone else meets. The user is not told this is what the vote button does.
